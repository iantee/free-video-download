# 秒存 — 需求分析（第一期）

后续加功能前先读本文和 [design.md](design.md)。行为变更必须同步改这两份文档。

## 1. 背景与问题

很多同学需要把视频保存到本地，但常见平台存在这些摩擦：

- 官方不提供下载，或入口藏得很深
- 不支持批量、清晰度受限、要登录/会员才给高清
- 手机浏览器里保存步骤长，不能随时随地拿走

本项目做一款本机可跑的 **万能视频下载网站「秒存」**：粘贴链接即可解析、选清晰度、下载到电脑或手机。下载能力不自研，全部交给开源项目 [yt-dlp](https://github.com/yt-dlp/yt-dlp)。

## 2. 目标用户与使用场景

- **谁用**：需要把课程、自己的内容、或有权保存的公开内容存到本地的同学
- **怎么用（第一期）**：本机或小范围演示，不是公开大规模盗链站
- **在哪用**：电脑浏览器 + 手机浏览器

不是：面向全网匿名用户的公开下载 SaaS。公开上线所需的限流、队列、风控不在本期范围。

## 3. 产品原则

1. **促付费但不花哨**：UI 对标 [鱼皮 AI 绘图提示词页](https://ai.codefather.cn/painting) 的干净目录/工具站气质（半透明顶栏、超粗标题、胶囊输入、亮蓝 CTA、轻阴影卡片）。只借设计语言，不抄品牌名和 Logo。
2. **后端轻量**：第一期无数据库、无账号。任务放内存，文件放临时目录，下完可删。
3. **站在巨人肩膀上**：不 fork yt-dlp，不自己写各平台解析器。只用官方 Python API 薄封装。
4. **失败要可见**：解析失败、无字幕、未配置 LLM Key，都用明确文案，禁止假成功。
5. **合规默认**：仅供用户下载自己有权保存的内容；不针对 DRM。

## 4. 第一期范围

### 4.1 做

| 能力 | 说明 |
| --- | --- |
| 链接解析 | 粘贴 URL，展示封面、标题、时长、上传者、可用清晰度 |
| 单条下载 | 用户选清晰度（约 360/720/1080/最佳画面/仅音频），进度可见，浏览器保存文件 |
| 播放列表 | 只列出条目，点选其中一条再解析/下载。完整批量是 Pro 卖点占位 |
| AI 学习页 | 可不下载：粘贴链接点「AI 总结」。基于字幕生成概述、要点、带时间戳章节；笔记按 Markdown 排版渲染。可对照字幕、追问、复制/导出 Markdown。思维导图用同一次笔记在页面上展开，可全屏阅读并下载整张高清图，不另调模型 |
| 字幕翻译 | 基于字幕或转写文本。页面按钮译成中文；接口 `target_lang` 另支持 `en`，页面还没有语言切换 |
| 字幕文件 | 解析后可单独下载 `.srt`，不必先总结、也不需要 LLM Key。没有平台字幕时走 Whisper，失败要明确报错。已总结过则复用这次完整字幕，不再转写一次 |
| 无字幕转写 | 没有可提取字幕时，下载音频并用本机 Whisper 转写，再走同一套学习页。转写失败要明确报错 |
| Pro 视觉 | 定价卡、角标、「升级」弹层。不接真实支付。本机演示 **不真锁死** 功能，便于验收 |
| 移动端 | 窄屏单列，下载走浏览器原生保存 |

### 4.2 明确不做

- 账号 / 登录 / 用户系统
- 数据库
- 真实支付（微信/支付宝/Stripe 等）
- 公开站级限流、任务队列、多 worker
- 破解 DRM、登录态抓取付费墙后的内容
- 修改 yt-dlp 源码

## 5. 核心用户路径

```text
打开首页，粘贴视频链接
  → 点「免费解析」：封面 / 标题 / 清晰度 → 可选「下载到本地」
  → 或点「AI 总结」：同一条链接先解析，再打开学习页（不必下载）
学习页（已配 LLM Key）：
  → 有可提取字幕：直接生成笔记
  → 没有可提取字幕（含硬字幕、未登录拿不到的 B 站 CC）：下载音频，Whisper 转写后再生成笔记
  → 学习笔记：概述 + 要点 + 带时间戳章节，按 Markdown 排版显示（标题、列表、强调），复制/导出仍是 Markdown 原文
  → 思维导图：用这次笔记的概述、章节、要点展开，不另调模型、不落库。可全屏缩放阅读，并下载整张高清 PNG
  → 字幕对照：时间戳 + 原文（转写时是语音文本）
  → 下载字幕：结果区或学习页都可以单独保存 `.srt`。不调用模型；已有学习会话时直接用本次完整字幕
  → 字幕翻译：页面按钮译成中文；接口另支持英文，页面还没有语言切换
  → 追问：针对本视频提问（只留在当前页，learn_id 存在内存约 30 分钟）
  → 复制 / 导出 Markdown 原文
失败：
  → 浏览器锁住 Cookie：解析和总结继续走未登录。没有 CC 就转写，不把锁文件当成失败
  → 转写失败或未安装 faster-whisper：明确报错，不把空转写做成笔记
  → B 站弹幕不算字幕；Cookie 仍可用于直接拉取 CC，拉到则优先用平台字幕
  → 浏览器锁住 Cookie 时：B 站仍应能解析；失败文案按站点区分，禁止对 B 站链接提示「打开一次抖音」
  → 未配置 LLM_API_KEY：提示去配 Key，不假成功
若链接是播放列表：
  → 先列出条目，点选一条后再下载或总结
```

## 6. 付费叙事（视觉，非真实扣费）

免费强调：**马上能下、手机也能用**。

Pro 卡与弹层突出：

- 4K / 更高清晰度
- 播放列表批量下载
- AI 视频总结
- 字幕翻译

第一期本机环境不根据「是否 Pro」拦截接口。角标和弹层只负责转化感和后续扩展位。真要接支付时，在 [design.md](design.md) 的扩展点改，而不是先加锁再补支付。

## 7. 合规

- 页脚和 README 写明：用户须确保对所下载内容拥有相应权利（自己的作品、授权、许可协议允许保存的内容等）
- 不提供 DRM 绕过说明或实现
- 不把站点宣传成「破解会员 / 无视版权」
- 默认配置面向本机演示，避免被当成公开盗链服务

## 8. 非功能

- 本机单进程即可运行（FastAPI + uvicorn）
- 合并视频+音频需要系统已安装 ffmpeg
- 下载文件用完即删（服务一次后或超时清理），不长期占盘
- 手机浏览器可完成解析和下载
- AI 依赖外部 LLM，允许未配置 Key 时其余功能仍可用

## 9. 验收清单（第一期）

- [ ] 首页视觉接近参考站气质：胶囊解析条、亮蓝主按钮、卡片轻阴影、移动端不乱
- [ ] 解析一条可测视频：封面、标题、清晰度列表出现
- [ ] 选较低清晰度能下载到本地文件，进度有反馈
- [ ] 播放列表链接能列出条目并点选一条
- [ ] 未配置 `LLM_API_KEY` 时，AI 按钮给出配置提示，不假成功
- [ ] 无平台字幕时走 Whisper 转写；转写失败或未安装时明确报错，不假成功
- [ ] 已配置 Key 且有字幕或转写文本时：概述、要点、带时间戳章节、字幕对照可见
- [ ] 总结成功后，学习笔记以排版后的 Markdown 显示，不把 `#`、`-` 原文直接铺在页面上
- [ ] 总结成功后，「思维导图」用同一份笔记展开概述、章节和要点；笔记为空时不画假导图
- [ ] 思维导图可全屏阅读（缩放、拖拽），并下载包含全部节点的高清 PNG
- [ ] 不配置 LLM Key 也能单独下载 `.srt`；已总结过再下载不重复转写
- [ ] 首页「AI 总结」不点下载也能出学习笔记；「免费解析」仍可只下载
- [ ] 追问能基于本视频字幕回答；复制 / 导出 Markdown 可用
- [ ] 页脚有使用免责声明
- [ ] 窄屏（约 390px）顶栏、输入条、结果区、学习 Tab 可单列使用
