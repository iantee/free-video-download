# 秒存 — 需求分析（第一期）

后续加功能前先读本文和 [design.md](design.md)。行为变更必须同步改这两份文档。

## 1. 背景与问题

很多同学需要把视频保存到本地，但常见平台存在这些摩擦：

- 官方不提供下载，或入口藏得很深
- 不支持批量、清晰度受限、要登录/会员才给高清
- 手机浏览器里保存步骤长，不能随时随地拿走

本项目做一款本机可跑的 **万能视频下载网站「秒存」**：粘贴链接即可解析、选清晰度、下载到电脑或手机。下载能力不自研，全部交给开源项目 [yt-dlp](https://github.com/yt-dlp/yt-dlp)。

## 2. 目标用户与使用场景

- **谁用**：需要把课程、自己的内容、或有权保存的公开内容存到本地的同学
- **怎么用（第一期）**：本机或小范围演示，不是公开大规模盗链站
- **在哪用**：电脑浏览器 + 手机浏览器

不是：面向全网匿名用户的公开下载 SaaS。公开上线所需的限流、队列、风控不在本期范围。

## 3. 产品原则

1. **促付费但不花哨**：UI 对标 [鱼皮 AI 绘图提示词页](https://ai.codefather.cn/painting) 的干净目录/工具站气质（半透明顶栏、超粗标题、胶囊输入、亮蓝 CTA、轻阴影卡片）。只借设计语言，不抄品牌名和 Logo。
2. **后端轻量**：第一期无数据库、无账号。任务放内存，文件放临时目录，下完可删。
3. **站在巨人肩膀上**：不 fork yt-dlp，不自己写各平台解析器。只用官方 Python API 薄封装。
4. **失败要可见**：解析失败、无字幕、未配置 LLM Key，都用明确文案，禁止假成功。
5. **合规默认**：仅供用户下载自己有权保存的内容；不针对 DRM。

## 4. 第一期范围

### 4.1 做

| 能力 | 说明 |
| --- | --- |
| 链接解析 | 粘贴 URL，展示封面、标题、时长、上传者、可用清晰度 |
| 单条下载 | 用户选清晰度（约 360/720/1080/最佳画面/仅音频），进度可见，浏览器保存文件 |
| 播放列表 | 只列出条目，点选其中一条再解析/下载。完整批量是 Pro 卖点占位 |
| AI 总结 | 基于 yt-dlp 拉到的字幕或自动字幕，调用 OpenAI 兼容 LLM 生成中文总结 |
| 字幕翻译 | 同样基于字幕文本，翻译为中文或英文 |
| Pro 视觉 | 定价卡、角标、「升级」弹层。不接真实支付。本机演示 **不真锁死** 功能，便于验收 |
| 移动端 | 窄屏单列，下载走浏览器原生保存 |

### 4.2 明确不做

- 账号 / 登录 / 用户系统
- 数据库
- 真实支付（微信/支付宝/Stripe 等）
- Whisper 或任何本地语音转写（无字幕则 AI 失败）
- 公开站级限流、任务队列、多 worker
- 破解 DRM、登录态抓取付费墙后的内容
- 修改 yt-dlp 源码

## 5. 核心用户路径

```text
打开首页
  → 粘贴视频链接，点「免费解析」
  → 看到封面 / 标题 / 清晰度 chips
  → 选清晰度，点「下载到本地」（看进度，浏览器弹出保存）
可选：
  → 点「AI 总结」或「字幕翻译」
  → 有字幕且已配 LLM Key：展示结果
  → 无字幕 / 无 Key：页面明确报错
若链接是播放列表：
  → 先列出条目，点选一条后走上面的单条路径
```

## 6. 付费叙事（视觉，非真实扣费）

免费强调：**马上能下、手机也能用**。

Pro 卡与弹层突出：

- 4K / 更高清晰度
- 播放列表批量下载
- AI 视频总结
- 字幕翻译

第一期本机环境不根据「是否 Pro」拦截接口。角标和弹层只负责转化感和后续扩展位。真要接支付时，在 [design.md](design.md) 的扩展点改，而不是先加锁再补支付。

## 7. 合规

- 页脚和 README 写明：用户须确保对所下载内容拥有相应权利（自己的作品、授权、许可协议允许保存的内容等）
- 不提供 DRM 绕过说明或实现
- 不把站点宣传成「破解会员 / 无视版权」
- 默认配置面向本机演示，避免被当成公开盗链服务

## 8. 非功能

- 本机单进程即可运行（FastAPI + uvicorn）
- 合并视频+音频需要系统已安装 ffmpeg
- 下载文件用完即删（服务一次后或超时清理），不长期占盘
- 手机浏览器可完成解析和下载
- AI 依赖外部 LLM，允许未配置 Key 时其余功能仍可用

## 9. 验收清单（第一期）

- [ ] 首页视觉接近参考站气质：胶囊解析条、亮蓝主按钮、卡片轻阴影、移动端不乱
- [ ] 解析一条可测视频：封面、标题、清晰度列表出现
- [ ] 选较低清晰度能下载到本地文件，进度有反馈
- [ ] 播放列表链接能列出条目并点选一条
- [ ] 未配置 `LLM_API_KEY` 时，AI 按钮给出配置提示，不假成功
- [ ] 无字幕且无自动字幕时，AI 提示「该视频没有字幕，无法总结/翻译」
- [ ] 已配置 Key 且视频有字幕时，总结和翻译有可见结果
- [ ] 页脚有使用免责声明
- [ ] 窄屏（约 390px）顶栏、输入条、结果区可单列使用

## 10. 后续候选（只列方向，不在一期做）

| 方向 | 备注 |
| --- | --- |
| 真实支付 | 先定套餐再接渠道，再决定是否锁 4K/批量/AI |
| 账号 | 支付和用量统计的前提 |
| 完整批量 | 播放列表一键队列下载 |
| Whisper | 无字幕视频的转写，体积和耗时都大 |
| 公开上线 | 限流、磁盘配额、并发、违法内容处理 |
| 数据库 | 替换内存 jobs，保留文件清理策略 |

相关实现与扩展钩子见 [design.md](design.md)。
